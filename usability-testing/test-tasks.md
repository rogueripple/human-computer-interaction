# Usability Test Tasks

These tasks are written as user goals. The facilitator should avoid telling participants exactly which button, icon, or menu to use.

## Task 1 — Find the cafeteria
**Scenario:** You are using the Smart Cafeteria application for the first time and want to find the cafeteria/service area you need.

**Goal:** Locate the relevant cafeteria information.

**Observe:** First navigation choice, labels understood, hesitation, and whether the participant reaches the correct screen.

## Task 2 — Find today's food/menu information
**Scenario:** You want to know what food or menu options are available today.

**Goal:** Find and understand today's menu information.

**Observe:** Whether the menu is easy to discover and whether the information is clear.

## Task 3 — Find an item or meal
**Scenario:** You have a particular meal/item in mind and want to check whether it is available.

**Goal:** Locate the item and determine its availability/details.

**Observe:** Search/navigation behaviour, filtering or category comprehension, and errors.

## Task 4 — Place or simulate an order
**Scenario:** You have selected something you want from the cafeteria and want to proceed with the ordering process.

**Goal:** Complete the prototype's ordering flow up to the point supported by the prototype.

**Observe:** Button labels, form clarity, confirmation/feedback, and points where the participant hesitates.

## Task 5 — Check order/status information
**Scenario:** You have already placed an order and want to know its current status or details.

**Goal:** Find the relevant order/status information.

**Observe:** Whether users know where to find previous/current orders and whether status information is understandable.

## Task 6 — Navigate to another major feature
**Scenario:** After completing a task, you want to use another major feature of the application.

**Goal:** Navigate from the current screen to another main section and return to the home/main screen.

**Observe:** Navigation consistency, back/home controls, and whether the information architecture makes sense.

## Task 7 — Recover from an unexpected screen
**Scenario:** You have opened a screen by mistake and want to return to where you were.

**Goal:** Return to the previous or main screen without assistance.

**Observe:** Back navigation, cancellation controls, and error recovery.

## Post-Test Questions
1. What was easiest to use?
2. What was most confusing?
3. Was there anything you expected to find but could not?
4. Which labels or icons were unclear?
5. What would you change about the application?
6. Would you feel comfortable using this application without assistance? Why?
