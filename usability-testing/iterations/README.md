# Design Iterations

This folder records how usability findings are converted into prototype improvements.

## Recommended Structure

```text
iterations/
├── README.md
├── iteration-1/
│   └── notes.md
└── iteration-2/
    └── notes.md
```

## Iteration Workflow
1. Record the usability issue.
2. Identify the affected screen/task.
3. Describe the proposed design change.
4. Update the prototype.
5. Retest the affected task.
6. Record whether the issue was resolved.

## Iteration Record Template

### Issue
[Reference a finding such as U-01.]

### Evidence
[What participants did.]

### Design Change
[What was changed in the prototype.]

### Reason
[Why the change addresses the usability problem.]

### Retest Result
[What happened after the change.]

### Status
Open / Improved / Resolved
